## ✨ 产品简介

**GameOps** 是一款专为游戏运营团队打造的 AI 驱动决策平台，致力于将**零散、情绪化的业务需求**转化为**结构化的可执行策略**。

核心功能涵盖五大模块：

- 🧠 **需求提交与策略生成** — 支持自然语言输入，AI Agent 自动匹配最优方案，并提供"直接 AI 生成"与"知识库 RAG 生成"双路径选择
- 🎨 **AI 配图生成** — 基于 Gemini 模型，一键生成活动专属视觉素材
- 📚 **知识库管理** — 沉淀节日策略、经验案例与舆情模板，构建团队专属运营智库
- 🧪 **A/B 测试建议** — 针对同一需求同步输出多套方案，附带预期效果与风险评估，助力数据驱动决策
- 📊 **运营效果追踪** — 实现策略执行后的指标闭环回流，让每一次决策都有据可查

平台**当月建议采用率达 78%**，帮助团队将**平均决策周期压缩至 2.4 天**，是提升游戏运营效率的得力 AI 助手。
